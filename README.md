# Zource
International Télécommunications Union

## Description

Ce projet présente un guide complet des stratégies langagières HTML pour créer des pages web internationalement accessibles. Il rassemble toutes les techniques recommandées par l'Union Internationale des Télécommunications pour l'internationalisation du contenu web.

## Structure du Projet

### Document de Référence
- **international telecommunications union.txt** - Document source contenant les 8 stratégies langagières HTML

### Code Complet et Unifié
- **complete_unified_code.html** - Fichier principal qui rassemble TOUTES les stratégies en un seul document HTML complet et fonctionnel
- **index.html** - Page d'accueil avec navigation vers tous les exemples

### Exemples Individuels
Chaque stratégie est démontrée dans un fichier séparé:
1. **strategy1_lang_attribute.html** - Déclaration de langue (attribut lang)
2. **strategy2_charset.html** - Encodage de caractères (UTF-8)
3. **strategy3_text_direction.html** - Direction du texte (dir attribute)
4. **strategy4_multilang_tags.html** - Balises de langue multiples
5. **strategy5_meta_multilingual.html** - Métadonnées multilingues
6. **strategy6_translate_attr.html** - Attribut translate
7. **strategy7_hreflang.html** - Accessibilité linguistique (hreflang)
8. **strategy8_bidi.html** - Texte bidirectionnel (BDI et BDO)

## Les 8 Stratégies Langagières HTML

1. **Déclaration de langue** - Utiliser l'attribut `lang` sur l'élément `<html>`
2. **Encodage de caractères** - Déclarer UTF-8 avec `<meta charset="UTF-8">`
3. **Direction du texte** - Utiliser l'attribut `dir` (ltr/rtl/auto)
4. **Balises multilingues** - Marquer les changements de langue avec `lang`
5. **Métadonnées** - Ajouter des balises meta pour le SEO linguistique
6. **Contrôle de traduction** - Utiliser l'attribut `translate` (yes/no)
7. **Versions alternatives** - Déclarer avec l'attribut `hreflang`
8. **Texte bidirectionnel** - Utiliser `<bdi>` et `<bdo>` pour contenu mixte

## Utilisation

Ouvrez `index.html` dans un navigateur pour accéder à:
- La documentation complète
- Le code unifié avec toutes les stratégies
- Les exemples individuels de chaque stratégie

Le fichier `complete_unified_code.html` est le résultat final qui combine toutes les stratégies en un seul document HTML complet et fonctionnel.

## Objectif

Ce projet démontre comment créer des pages web accessibles internationalement en appliquant les meilleures pratiques d'internationalisation HTML recommandées par l'ITU.
