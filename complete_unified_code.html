Introduction

Ce document démontre l'application complète et unifiée de toutes les stratégies langagières HTML recommandées par l'International Telecommunications Union pour créer des pages web internationalement accessibles.

Stratégie 1: Déclaration de Langue (attribut lang)

L'attribut lang est défini sur l'élément <html> pour déclarer la langue principale du document.

<html lang="fr" dir="ltr">

Codes ISO 639-1 pour différentes langues:

  • fr - Français
  • en - Anglais
  • es - Espagnol
  • de - Allemand
  • ar - Arabe
  • zh - Chinois

Stratégie 3: Direction du Texte (attribut dir)

Texte gauche-à-droite (LTR):

Texte français de gauche à droite.

English text from left to right.

Texte droite-à-gauche (RTL):

هذا النص العربي يظهر من اليمين إلى اليسار

טקסט עברי מימין לשמאל

Détection automatique:

Mixed content with العربية and English

<p dir="ltr">Left to right</p>
<p dir="rtl">Right to left</p>
<p dir="auto">Automatic</p>

Stratégie 4: Balises de Langue Multiples

Utilisez l'attribut lang sur des éléments spécifiques pour marquer du contenu dans différentes langues:

Salutations en différentes langues:

  • Bonjour (Français)
  • Hola (Español)
  • Guten Tag (Deutsch)
  • Ciao (Italiano)
  • Olá (Português)

  • Привет (Русский)

<span lang="en">Hello</span>
<span lang="ar">مرحبا</span>

Stratégie 5: Métadonnées Multilingues

Les balises meta suivantes sont utilisées dans ce document:

<meta name="language" content="French">
<meta http-equiv="content-language" content="fr">

Ces métadonnées aident:

  • Les moteurs de recherche à indexer correctement le contenu
  • Les navigateurs à appliquer les bonnes règles linguistiques
  • Les outils de traduction à identifier la langue source

Stratégie 6: Attributs Translate

Ce paragraphe peut être traduit automatiquement.

Éléments avec translate="no":

  • Nom d'organisation: International Telecommunications Union
  • Nom de produit: Zource
  • Nom de personne: Jean Dupont
  • Code informatique: console.log("Hello World");
  • Nom de marque: GitHub
<p translate="yes">Traduction autorisée</p>
<span translate="no">Pas de traduction</span>

Stratégie 7: Accessibilité Linguistique (hreflang)

L'attribut hreflang indique les versions alternatives du contenu:

Dans le <head>:

<link rel="alternate" hreflang="en" href="/en/index.html">
<link rel="alternate" hreflang="es" href="/es/index.html">
<link rel="alternate" hreflang="x-default" href="/en/index.html">

Dans les liens:

Versions disponibles:

  • Version française
  • English version
  • Versión española
  • Deutsche Version

Avantages pour le SEO:

  • Meilleur classement dans les résultats de recherche locaux
  • Évite le contenu dupliqué
  • Améliore l'expérience utilisateur internationale

Stratégie 8: BDI et BDO pour Texte Bidirectionnel

Isolation bidirectionnelle avec <bdi>:

Utile pour afficher des noms d'utilisateur ou des données qui peuvent être dans différentes directions:

Utilisateur 1: مستخدم123 (arabe)

Utilisateur 2: User456 (latin)

Utilisateur 3: משתמש789 (hébreu)

Override de direction avec <bdo>:

Force une direction spécifique:

Texte normal: ABCDEFGHIJKLMNOPQRSTUVWXYZ

Texte inversé (RTL): ABCDEFGHIJKLMNOPQRSTUVWXYZ

Contenu mixte LTR/RTL:

English text with embedded نص عربي مضمن in the middle.

نص عربي مع embedded English text في الوسط.

<bdi>مستخدم</bdi> - Isolation
<bdo dir="rtl">TEXT</bdo> - Override

Bonnes Pratiques - Résumé

  1. Toujours déclarer l'attribut lang sur <html>
  2. Utiliser UTF-8 comme encodage de caractères
  3. Spécifier la direction du texte (dir="ltr" ou dir="rtl") si nécessaire
  4. Marquer les changements de langue avec lang sur les éléments
  5. Ajouter des métadonnées linguistiques pour le SEO
  6. Contrôler la traduction avec l'attribut translate
  7. Déclarer les alternatives linguistiques avec hreflang
  8. Gérer le texte bidirectionnel avec <bdi> et <bdo>
